# 3D workspace

The plan area of every main window (ADR-060) — no switch; View → "3D View" shows its 3D pane (FR-SUN-06).

- **FR-3D-WS-01** (L1.3): The plan area of the main window has three modes — **Plan** (the plan alone, as before), **3D** (the garden in 3D) and **Split** (both, side by side, with a divider the user can drag; neither side can be dragged shut). They are switched with a button row on the view, with View → Workspace, or with Alt+1 / Alt+2 / Alt+3. The Split position is remembered between sessions (kept the moment Split is left). The selection is kept in every mode — in 3D mode the ring and the info card show it (FR-3D-SELECT-01, L1.8).
- **FR-3D-WS-02** (L1.3): Nothing of 3D is started before the user first asks for it; a session that never opens 3D pays nothing for it. The first switch shows "Building the 3D view…" before the garden is built.
- **FR-3D-WS-03** (L1.3): While 3D is visible, every edit of the plan — draw, move, resize, rotate, recolour, delete, undo, redo, a typed height, a layer shown / hidden / locked, arrange, group, paste, duplicate, an agent's write, a value typed into the Properties panel — appears in 3D without a rebuild of the scene and without a step by the user. On the reference plan of about 100 objects an edit is in a finished 3D frame within 50 ms (95th percentile, measured: 21 ms). What only REPAINTS the plan — a hover, a selection, a tool's preview under the mouse, the sun's shadows while the time moves or "Animate" runs — costs 3D nothing: a preview mouse move costs the same in Split as in Plan.
- **FR-3D-WS-04** (L1.3): While 3D is hidden (Plan mode, another tab, a minimised window) it does no work; when it is shown again it catches up in one step.
- **FR-3D-WS-05** (L1.3): The 3D view follows the sun toolbar: a time of day moves the light at once; a date regrows the dated plants.
- **FR-3D-WS-06** (L1.3): The user moves the 3D camera — drag to pan, right-drag to orbit, wheel or both buttons to zoom, arrow keys, Alt+arrows, PageUp / PageDown — and it glides to a stop. **Editing the plan never moves it.** Only the user, "Reset 3D View" (Home), the first open and a new or opened plan change the view. The camera cannot go below the ground or lose the plan.
- **FR-3D-WS-07** (L1.3): If 3D did not start properly the last time (the graphics driver ended the program), the next session shows 3D in a **compatibility mode** (software rendering), says so, and offers "Try Hardware Next Time". If the graphics device cannot be used at all, the 3D pane says so and offers compatibility mode for the next start. If 3D did not start in compatibility mode either, it is switched off and the pane says so. In every one of these states "Try Hardware Next Time" is on screen while compatibility mode is on. The rest of the application is never affected.
- **FR-3D-WS-08** (L1.3): An object that cannot be shown in 3D (for example an outline too large to build) is never silently missing: the 3D pane shows how many objects are not shown, and a list names each with the reason and selects it on the plan when chosen (at most 200 entries, then how many more). Fixing the object clears its entry. Every notice of the 3D pane is shown whole, also in a narrow pane (Split in a 1366 px window), in every language.
- **FR-3D-WS-09** (L1.3): The application's shortcuts keep working while the 3D view has the keyboard (Ctrl+Z undoes).
- **FR-3D-WS-10** (L1.3): The fullscreen preview hides the workspace's controls with the rest of the interface.
- **FR-3D-WS-11** (L1.3): A new, opened or recovered plan replaces the garden in 3D and is framed once. A plan that could NOT be opened (a damaged file, a recent file that was moved, an agent's `open_plan` on a bad file) changes nothing: the 3D view, its camera and the open plan's hours-of-sun map stay as they were (FR-SUN-10 is the requirement for the map itself).
- **FR-3D-WS-12** (L1.9): The workspace is part of every main window — no setting, menu entry or environment variable turns it off — and starting the app costs nothing of the 3D engine: Qt Quick 3D is loaded the first time 3D or Split is chosen, never at start-up (measured: no engine module after starting, opening a plan and closing without 3D). The safety net for a graphics device that fails is FR-3D-WS-07's compatibility mode, not a switch; the app always starts in Plan mode.
- **FR-3D-WS-13** (L1.9): View → "3D View" (where the Qt 3D window used to open, with its icon) shows the 3D pane: from Plan mode it switches to Split, in 3D or Split mode it changes nothing; no separate window exists. Help → Keyboard Shortcuts lists Alt+1 / Alt+2 / Alt+3, the 3D camera's mouse and keys, Home, a click that selects, and walk mode's keys. Preferences → 3D View is offered in every main window.
- **FR-3D-WS-14** (L1.9, #531): While the plan date keeps changing — an arrow key held in the date field steps it about 30 times a second — the 3D view regrows its dated plants at most twice a second: the first date at once, the last one when the half second is over, and never the day before the last. The light follows every step at once. A minute of a held key regrows a fraction of the plants it regrew before (measured in §8.29.9).
