# Canvas Rendering Pitfalls (PF-CAN, 01b)

| ID | Rule | Status | Where | Legacy |
|---|---|---|---|---|
| PF-CAN-49 | Qt keeps every item's `DeviceCoordinateCache` picture in the process-wide `QPixmapCache`, whose default limit is 10 MB; a canvas raises it (`ui/canvas/item_cache.ensure_item_cache_budget`, 256 MB) or its item caches thrash and every repaint paints the items again. Setting a cache mode proves nothing: count the paints. | standing | [01b](../01b-canvas-rendering.md#pf-can-49) |  |
| PF-CAN-50 | A bitmap drawn through a painter is rasterised for THAT painter: ask `core/raster_resolution` (device scale of the painter, rounded up to a power of two, never below 1) through `paint_plant` / `paint_furniture` / `brush_for_painter`, never hand a renderer the item's size in centimetres as pixels, and never rasterise a sprite whole when it would exceed 1024 px a side. | standing | [01b](../01b-canvas-rendering.md#pf-can-50) |  |
| PF-CAN-51 | Whatever marks an object (selection handles, the rotation handle, a label anchor) reads `handle_geometry.selection_frame_rect(item)`, never `boundingRect()`; and an `ItemIgnoresTransformations` label is centred or stacked in its own pixel frame, never by an offset written into its position. | standing | [01b](../01b-canvas-rendering.md#pf-can-51) |  |
| PF-CAN-52 | Text that the view scales (a `TextItem` note, a callout) is laid out unhinted (`PreferNoHinting`); text with a halo strokes the glyph outline path, because `drawText` with a wide pen outlines nothing, and takes that outline from the layout that draws the glyphs, never from `QPainterPath.addText`; and a label that shows text from the plan shows a bounded text (`halo_text.label_text`), because stroking outlines costs what the text is long. | standing | [01b](../01b-canvas-rendering.md#pf-can-52) |  |
| PF-CAN-53 | The scene is never painted into a `QSvgGenerator` directly: it is painted into the recording engine of `services/svg_export.py` and replayed, because the generator drops a brush's own transform and a pixmap's source rectangle, and writes a clip either not at all or as a staircase. | standing | [01b](../01b-canvas-rendering.md#pf-can-53) |  |
| PF-CAN-54 | A `paint()` clips with `Qt.ClipOperation.IntersectClip`, never with the default `ReplaceClip`: the painter it is handed already carries the clip of a print tile or a report frame, and replacing it paints on the margin. | standing | [01b](../01b-canvas-rendering.md#pf-can-54) |  |
| PF-CAN-55 | A scale bar's length is its label's distance at the scale its picture was painted at: pick a round distance that fits, never clamp the bar, and take the scale from the fitted rectangle, not from the frame's width. | standing | [01b](../01b-canvas-rendering.md#pf-can-55) |  |
| PF-CAN-56 | Code that authors an item (a generator, a fixture builder, a tool) turns it with `geometry_apply.apply_rotation`, never with a bare `QGraphicsItem.setRotation`: the bare call turns about the item's origin and is not the `rotation_angle` the serializer saves, so the item is saved unrotated and at another place. | standing | [01b](../01b-canvas-rendering.md#pf-can-56) |  |
| PF-CAN-57 | A soft edge is a field, not strokes: a stroke has one tone, so stacked strokes are flat bands that show as stripes once the zoom makes them wider than a pixel or two. Rasterise the shape on a coarse lattice anchored in the plan, blur it, map the blurred coverage to the falloff (`core/soft_edge`), enlarge that with filtering, clamp it to the shape's own tone THERE (blurred coverage is a distance beside a straight edge only) and cut the shape out again in a device layer — never with a clip. | standing | [01b](../01b-canvas-rendering.md#pf-can-57) |  |
| PF-CAN-58 | A scene finds the items of a picture by their rectangles taken WITHOUT the painter's transform, and for an item that ignores transformations that rectangle is in pixels around its anchor: one that lies on one side of the anchor is outside a y-flipped `scene.render()` and the item is not painted at all. Give it a `boundingRect()` that reaches across the anchor (the rectangle united with its mirror image). | standing | [01b](../01b-canvas-rendering.md#pf-can-58) |  |
| PF-CAN-59 | Text that an item draws by hand (`painter.setFont` + `drawText`) is drawn with a font sized in pixels (`ui/canvas/layout_font.device_independent`), and every measure around it is a share of that font: a font in points is resolved by each painter for its own device, while `QFontMetricsF(font)` answers for the screen. | standing | [01b](../01b-canvas-rendering.md#pf-can-59) |  |
| PF-CAN-60 | What a paint needs of the WHOLE scene (what stands on the plan, which labels have room) is kept in plan coordinates and taken again only when `CanvasScene.paint_revision` has moved, never walked for a paint; and `QGraphicsScene.changed` is not that revision: it cannot tell an edit from a tool's preview, a hover or a shadow that moved, it is silent when an item that ignores transformations is hidden or shown, and it reaches a slot only when the event loop runs — every place that changes what is kept says so itself. | standing | [01b](../01b-canvas-rendering.md#pf-can-60) |  |
| PF-CAN-61 | A method that Qt calls on a view, a scene or an item while another object of the same garbage is destroyed (a virtual such as `scrollContentsBy`, a slot on a signal Qt emits from a destructor) reads only attributes that have a class-level default: the cyclic collector clears an object's `__dict__` before it destroys its C++ part, and an `AttributeError` raised inside a Qt-called virtual ends the process without a traceback. | standing | [01b](../01b-canvas-rendering.md#pf-can-61) |  |
| PF-CAN-62 | A print page's order and decoration belong to the page's own transform. Anchor fixed-scale rows at the TOP of the plan so a non-whole tile leaves the short row LAST; draw the optional grid after the scene at the canvas's spacing with a pen stated in millimetres, because a cosmetic pixel at 1200 dpi is invisible. | standing | [01b](../01b-canvas-rendering.md#pf-can-62) |  |
| PF-CAN-63 | A kept picture is invalidated by the state it reads, and its consumer selects its render scope explicitly; a preview's repaint is no geometry edit, and a thumbnail is no live viewport clip. | standing | [01b](../01b-canvas-rendering.md#pf-can-63) |  |
| PF-CAN-64 | Never set C++ `ItemIgnoresTransformations` on every plan object's label child (`PlanLabelItem` tracks it in Python), drop `DeviceCoordinateCache` globally on crowded plants, drill into a group on `mousePress`, or feed unbounded text to `EditableLabel` / `QGraphicsTextItem`. | standing | [01b](../01b-canvas-rendering.md#pf-can-64) |  |
| PF-CAN-65 | Never cut a semi-transparent overlay out of a separate layer with plain `CompositionMode_DestinationOut` and then composite the interior with `CompositionMode_SourceOver` (`shadow_feather._cut_out_shade` compensates boundary pixels by `(1 - c) / (1 - c * alpha_s)`); and during rapid timeline scrubbing `SunShadowController` caches casters by `(paint_revision, plan_date)` and defers `paint_feather` until the scrub settles while keeping exports feathered. | standing | [01b](../01b-canvas-rendering.md#pf-can-65) |  |
| PF-CAN-66 | Bound dense polyline stroke paths (`> 256` vertices) with envelope-preserving bucket decimation (`path_style_paint.bounded_stroke_points`) and cosmetic selection pens even when selected or exported while preserving `self._points`; scale cosmetic contour pens in high-DPI exports (`sun_heatmap.SunContourItem`); and use contrast-preserving periodic mip tiles (`fill_patterns.COARSE_LEVELS`) below 50 % zoom so minification does not moire or fail the interior contrast guard. | standing | [01b](../01b-canvas-rendering.md#pf-can-66) |  |
| PF-CAN-67 | Compare the settled native viewport with two full repaints. "Settled" means the viewport produced two identical grabs 100 ms apart; the forced full repaint is the negative control for completeness. | standing | [01b](../01b-canvas-rendering.md#pf-can-67) |  |
| PF-CAN-68 | Export a raster picture no finer than the page it lands on: `raster_level` rounds a painter's scale UP to a power of two for the canvas, and a print painter meets that level with up to 1.7x the pixels a 300-dpi page shows. Fit each picture to one pixel per export unit (`svg_export._fit_picture`), measured by the lengths the state transform maps the target's edges onto (never a rotation-inflated bounding box), and never enlarge one. | standing | [01b](../01b-canvas-rendering.md#pf-can-68) |  |
| PF-CAN-69 | Capture both coordinates of a projected datum move; replay them without projection. | standing | [01b](../01b-canvas-rendering.md#pf-can-69) | |
| PF-CAN-70 | A command that moves a Qt item group must reconcile bed membership for every plant in the group's child tree, and must not add a bed-child delta to a plant a moved Qt ancestor already carries. Filtering the moved selection for plant types is not the set of plants it carries. Every move also names its delta frame: `scene` deltas are total scene displacements, `local` deltas are parent-relative. A scene residual applied to a Qt child is mapped into its parent's frame, and a bed's non-carried children follow the bed's NET scene delta - not the delta of the group that carries the bed and not the bed's own parent-local residual. | standing | [01b](../01b-canvas-rendering.md#pf-can-70) | |
