# Test Suite Hygiene Pitfalls (PF-TST)

| ID | Rule | Status | Where | Legacy |
|---|---|---|---|---|
| PF-TST-01 | A GUI-responsiveness test holds the real worker in flight with an Event and counts heartbeat ticks only while it runs on another thread, so the count cannot depend on compute duration. | standing | [07](../07-test-suite-hygiene.md#pf-tst-01) |  |
| PF-TST-02 | A within-day simulation test sets the time of day as well as the date, such as noon via `set_time_of_day`, rather than inheriting the host clock, changing clock semantics or relaxing timeouts. | standing | [07](../07-test-suite-hygiene.md#pf-tst-02) |  |
| PF-TST-03 | Every concrete placeable graphics item, `TextItem` included, round-trips through the `ProjectManager` serializer with exact dictionary equality, checked by one matrix over every item class. | standing | [07](../07-test-suite-hygiene.md#pf-tst-03) |  |
| PF-TST-04 | Pytest tears fixtures down in reverse setup order, so an ordering-sensitive teardown declares its dependencies such as `qtbot` explicitly, and a mechanism is verified before it is documented. | standing | [07](../07-test-suite-hygiene.md#pf-tst-04) |  |
| PF-TST-05 | A test that could reach a real external CLI stubs `shutil.which` for the whole module, so its default is no CLI rather than whatever happens to be installed on the developer's machine. | standing | [07](../07-test-suite-hygiene.md#pf-tst-05) |  |
| PF-TST-06 | Tests never call `QSettings.setDefaultFormat()` or `setPath()`, process-global statics Qt never reverts; they redirect the `create_qsettings` factory with `monkeypatch` instead. | standing | [07](../07-test-suite-hygiene.md#pf-tst-06) |  |
| PF-TST-07 | A full-app test that outlives the 500 ms startup timer silences the modal Welcome dialog, whose `exec()` otherwise blocks pytest-qt forever behind an empty log. | standing | [07](../07-test-suite-hygiene.md#pf-tst-07) |  |
| PF-TST-08 | Every settings store, `UiStateStore` included, takes its backend from `app/settings.create_qsettings()`, because a store that bypasses the chokepoint also bypasses the test isolation built on it. | standing | [07](../07-test-suite-hygiene.md#pf-tst-08) |  |
| PF-TST-09 | Isolating one store is not isolating the process, so every place the app touches (`get_app_data_dir`, `QStandardPaths`, `Path.home()`, the temp directory) is redirected in each process running it. | standing | [07](../07-test-suite-hygiene.md#pf-tst-09) |  |
| PF-TST-10 | A 'nobody may use X' gate walks the AST and matches the name binding rather than a regex over uses, and every detector has a positive control fed the exact escape it exists to catch. | standing | [07](../07-test-suite-hygiene.md#pf-tst-10) |  |
| PF-TST-11 | The Welcome dialog is silenced session-wide by a class patch in `tests/conftest.py`, not per file or by a settings write alone, and a QSettings key other live instances share is never `clear()`ed. | standing | [07](../07-test-suite-hygiene.md#pf-tst-11) |  |
| PF-TST-12 | A determinism gate on a compressed binary artifact such as a PNG compares decoded pixels, never file bytes, because different zlib builds can encode identical pixels to different bytes. | standing | [07](../07-test-suite-hygiene.md#pf-tst-12) |  |
| PF-TST-13 | A hidden texture wrap seam is located by measuring the per-column difference between row 0 and row 255, not by theorising about the layout, because the metric already knows where the seam is. | pointer | [07](../07-test-suite-hygiene.md#pf-tst-13) |  |
| PF-TST-14 | A `QTimer` in a widget takes the widget as parent, a debounced action stops its own timer when it runs, and a timer whose slot can open a modal is stopped in `done()` or `closeEvent`. | standing | [07](../07-test-suite-hygiene.md#pf-tst-14) |  |
| PF-TST-15 | Top-level JavaScript `let` bindings never land on `window`, so a readiness probe evaluates them in page scope (`typeof map !== 'undefined'`) or calls a status function the page exposes on `window`. | standing | [07](../07-test-suite-hygiene.md#pf-tst-15) |  |
| PF-TST-16 | A Qt test covers a timer handler by emitting the timer's `timeout` signal directly, never by starting a widget-owned short-interval timer inside a `qtbot.waitUntil` poll. | standing | [07](../07-test-suite-hygiene.md#pf-tst-16) |  |
| PF-TST-17 | A page-side JavaScript guard that compares a value echoed from Python stringifies both operands or stores the value stringified, because a number never strictly equals its string form. | standing | [07](../07-test-suite-hygiene.md#pf-tst-17) |  |
| PF-TST-18 | A performance test gates the median of repeated warmed samples and reports the sample list on failure, because one wall-clock sample on a shared runner cannot tell a scheduler spike from a regression. | standing | [07](../07-test-suite-hygiene.md#pf-tst-18) |  |
| PF-TST-19 | A green suite is evidence only about the paths it exercises, so a regression test reproduces the exposing condition, such as a preview over an existing item or a stop with a client attached. | standing | [07](../07-test-suite-hygiene.md#pf-tst-19) | 11.4.2 |
| PF-TST-20 | `qtbot.addWidget` only closes a widget, so a root-conftest autouse fixture `deleteLater()`s every top-level widget after each test and flushes `QEvent.Type.DeferredDelete` by name. | standing | [07](../07-test-suite-hygiene.md#pf-tst-20) |  |
| PF-TST-21 | A settings value tests rely on is written in the same fixture that wipes the store, never by a second fixture that merely depends on it, or for an instant an absent key reads the production default. | standing | [07](../07-test-suite-hygiene.md#pf-tst-21) |  |
| PF-TST-22 | A test never creates, stages or deletes files in the git working tree; it works in a throwaway `git init` repository under `tmp_path`, which stays safe under any scheduler and any interruption. | standing | [07](../07-test-suite-hygiene.md#pf-tst-22) |  |
| PF-TST-23 | Asking the OS for a free port and closing the socket is not a reservation, so one shared helper retries only the port-in-use failures and re-raises every other `RuntimeError` at once. | standing | [07](../07-test-suite-hygiene.md#pf-tst-23) |  |
| PF-TST-24 | A measurement that travels in an attribute is a wall-clock assertion too: the perf-marker guard follows the carrier into the local support modules, scoped to the class that owns it, and a value that is only counted is not a duration. | standing | [07](../07-test-suite-hygiene.md#pf-tst-24) |  |
| PF-TST-25 | A deterministic throttle test owns its clock origin and consumes any booked timer before manually invoking its slot. | standing | [07](../07-test-suite-hygiene.md#pf-tst-25) |  |
| PF-TST-26 | Font-metric claims are measured on a real font engine; offscreen Qt on Windows draws every glyph as a whole-pixel box. | standing | [07](../07-test-suite-hygiene.md#pf-tst-26) |  |
| PF-TST-27 | A probe that builds the app calls script_isolation's isolate_profile() and isolate() first; setDefaultFormat isolates nothing. | standing | [07](../07-test-suite-hygiene.md#pf-tst-27) |  |
| PF-TST-28 | Windows' `offscreen` Qt platform has no font database; every family resolves to a box engine whose glyphs are all one em wide. Register a real Windows face once in the session fixture and make it the application font before measuring a width, a row count or a rounding. `test_plan_timeline.py` registering `arial.ttf` inside one test and never removing it is the leak, not the fix. | standing | [07](../07-test-suite-hygiene.md#pf-tst-28) |  |
| PF-TST-29 | A probe that builds the app is refused the owner's real settings store when it runs under `offscreen`/`minimal`, or in an agent/tooling shell without the product's entry-point marker. `create_qsettings()` is the guard; `scripts/script_isolation.isolate()` and the product's `main.py` are the two sanctioned ways through. A throwaway QApplication name and `QSettings.setDefaultFormat()` redirect nothing. | standing | [07](../07-test-suite-hygiene.md#pf-tst-29) |  |
| PF-TST-30 | Apply `perf` to individual elapsed-time tests in a mixed class; deterministic signature, spy, fake-clock and geometry contracts belong in the parallel suite. | pointer | [07](../07-test-suite-hygiene.md#pf-tst-30) |  |
| PF-TST-31 | A render measurement waits for ground, camera LOD and forge admission, judges the sink-held meshes at zero wind phase, and distinguishes document reloads from unchanged same-document passes. | standing | [07](../07-test-suite-hygiene.md#pf-tst-31) |  |
| PF-TST-32 | Sample ground memory after two presented frames retire replaced uploads, preserve the leak bound and control, and never use a grab as a presentation. | standing | [07](../07-test-suite-hygiene.md#pf-tst-32) |  |
