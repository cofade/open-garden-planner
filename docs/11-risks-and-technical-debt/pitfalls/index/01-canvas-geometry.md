# Canvas Geometry Pitfalls (PF-CAN)

| ID | Rule | Status | Where | Legacy |
|---|---|---|---|---|
| PF-CAN-01 | A selected item paints without a device cache so its handles do not ghost, and an export clears every item cache so the render is full vector fidelity. | standing | [01](../01-canvas-geometry.md#pf-can-01) |  |
| PF-CAN-02 | A plant's icon and decorative drop-shadow draw at the shared plan date's growth-interpolated spread, while `rect()`, `pos()` and `transformOriginPoint()` keep the footprint that selection, snap and spacing read. | standing | [01](../01-canvas-geometry.md#pf-can-02) |  |
| PF-CAN-03 | Compute a plant's visual diameter once at the top of `paint()` and reuse it for both the drop-shadow and the icon, and prove such a change on a rendered frame, not on private helpers. | standing | [01](../01-canvas-geometry.md#pf-can-03) |  |
| PF-CAN-04 | Anchors of the same `AnchorType` each carry a unique `anchor_index` in `get_anchor_points()`, or `_resolve_anchor_position()` falls back to type-only matching and picks the first one. | standing | [01](../01-canvas-geometry.md#pf-can-04) |  |
| PF-CAN-05 | Positive scene Y is visually upward on the canvas, so an offset computed from a user-facing angle negates `dy` (`dy = -spacing * sin(angle_rad)`) to match screen intuition. | standing | [01](../01-canvas-geometry.md#pf-can-05) |  |
| PF-CAN-06 | A polygon or polyline `EDGE_*` anchor type changes when an edge's dominant axis flips, so `_resolve_anchor_position()` matches such anchors by index alone before any type-only fallback. | standing | [01](../01-canvas-geometry.md#pf-can-06) |  |
| PF-CAN-07 | A negative-height target such as `QRectF(0, H, W, -H)` is empty and makes `scene.render()` paint nothing; flip the painter instead, translating by the image height in pixels and scaling Y by -1. | standing | [01](../01-canvas-geometry.md#pf-can-07) |  |
| PF-CAN-08 | Outside a view, `scene.render()` draws `ItemIgnoresTransformations` items at device-pixel size, so every export gives those items — and only those — a point size for the output (`scene_rendering.retarget_constant_size_text`); a text note is sized in plan units and is never touched. | standing | [01](../01-canvas-geometry.md#pf-can-08) |  |
| PF-CAN-09 | A `QPdfWriter` gets `setResolution(72)` before `setPageLayout()`, so device pixels equal PDF points and layout math in points does not land in the top-left corner. | standing | [01](../01-canvas-geometry.md#pf-can-09) |  |
| PF-CAN-10 | Never call `scene.render()` directly on a `QPdfWriter` painter, whose margin transform breaks the Y-flip; render into a temporary `QImage` and embed it with `painter.drawImage()`. | standing | [01](../01-canvas-geometry.md#pf-can-10) |  |
| PF-CAN-11 | A plant item keeps `pos()` at (0, 0) with its geometry in local coordinates, so its scene centre is `item.mapToScene(item.boundingRect().center())`, never `pos()` or `scenePos()`. | standing | [01](../01-canvas-geometry.md#pf-can-11) |  |
| PF-CAN-12 | A pattern brush needs no flip of its own in an SVG export: the tile is in the user space of a group that carries the painter's Y-flip, exactly as on a `QImage`. What `QSvgGenerator` does drop is the brush's own transform, which the SVG recorder moves into the world transform (PF-CAN-53). | standing | [01](../01-canvas-geometry.md#pf-can-12) |  |
| PF-CAN-13 | `QSvgGenerator` writes no painter clip in its default SVG Tiny 1.2 mode, and `QSvgRenderer` ignores `clip-path` in any mode: an SVG export writes a clipped shape as geometry already cut to its clip (PF-CAN-53), and a test that rasterises with `QSvgRenderer` cannot see a `<clipPath>`. | standing | [01](../01-canvas-geometry.md#pf-can-13) |  |
| PF-CAN-14 | OGP scene Y and DXF Y both point up, so DXF export writes `dxf_y = scene_y` and import reads `scene_y = dxf_y * scale`, with no negation in either direction. | standing | [01](../01-canvas-geometry.md#pf-can-14) |  |
| PF-CAN-15 | Text drawn with `painter.drawText()` inside `paint()` is mirrored on the Y-flipped canvas; draw it as a child text item with `ItemIgnoresTransformations` instead. | standing | [01](../01-canvas-geometry.md#pf-can-15) |  |
| PF-CAN-16 | Anchor snap always wins over grid snap: `CanvasView.snap_point()` skips grid rounding while `_current_snap` is set, and any new snap layer needs an explicit composition rule. | standing | [01](../01-canvas-geometry.md#pf-can-16) |  |
| PF-CAN-17 | A raster drawn in item-local space with `painter.drawPixmap()` comes out upside-down under the scene's Y-flip, so the item must flip the painter back about the rect centre first. | standing | [01](../01-canvas-geometry.md#pf-can-17) |  |
| PF-CAN-18 | Over its vertex budget a cached polygon paint draws only a cosmetic-pen outline, keyed on cache mode not `widget`, and every item copy carries both its serialized look and its pen and brush. | standing | [01](../01-canvas-geometry.md#pf-can-18) | 11.4.9 |
| PF-CAN-19 | A textured fill is recoloured as a luminance map so a pale colour reads, the loader restores the stored look attributes, and round-trip tests compare rendered pixels in a non-default colour. | standing | [01](../01-canvas-geometry.md#pf-can-19) | 11.4.10 |
| PF-CAN-20 | A canvas texture may be softened but never replaced by a flat fill at any zoom, and the negative pin must sample the item's own `shape()` interior, since a mask on background reads as texture. | standing | [01](../01-canvas-geometry.md#pf-can-20) | 11.4.11 |
| PF-CAN-21 | Every writer that sets an item's style attributes or its live pen and brush sets both through `core/item_look.py`, so `style_gaps(item)` stays empty for every item that does not paint a sprite. | standing | [01](../01-canvas-geometry.md#pf-can-21) | 11.4.17 |
| PF-CAN-22 | The sun study's 2D overlays lie on the ground surfaces (`on_ground`, drawn in `GROUND_Z_RANGE` by `_refresh_layer_z`) and under everything else; Arrange stays in a band. | standing | [01](../01-canvas-geometry.md#pf-can-22) |  |
| PF-CAN-23 | A cached paint's `option.exposedRect` is the item's WHOLE rect, not the visible part. A styled line intersects it with the view's visible scene rect, in item coordinates, and passes that clip plus a `WalkBudget` to the one `PathStylePaint` walk; an export or minimap render disables caches first and keeps full detail. | standing | [01](../01-canvas-geometry.md#pf-can-23) |  |
| PF-CAN-24 | Stacking z is derived only from ranks. An appended independent solid takes the derivation's own next fixed-grid value at add time (one derivation per layer, never one per add), a re-ordering add (parent bed, children, roof ridge, pre-ranked re-add, ground surface) re-derives synchronously, and the per-layer cache that seeds the next value holds a LAYER-BAND number, never the highest `zValue`, so a ground-only layer (whose z lives in `GROUND_Z_RANGE`) seeds the next solid correctly. | standing | [01](../01-canvas-geometry.md#pf-can-24) |  |
| PF-CAN-25 | A per-command refresh is scoped to what the command can change: the lock badge refreshes only items carrying a FIXED constraint (or already showing a badge that may need clearing), and `CanvasScene._restack_ground_changes` classifies items only when `Command.changes_ground_band` is true. The base default stays true, so a new command is safe until it opts out with proof that it cannot change a type, a height or a group. | standing | [01](../01-canvas-geometry.md#pf-can-25) |  |
| PF-CAN-26 | A dense vertex-edit overlay stays sampled while the viewport remains inside the scene region the sample was taken over; a pan only translates the points, so the chosen indices keep their pairwise screen spacing. Re-sample on a zoom change, when the item's pose or geometry changes, or when the viewport leaves that region. Re-sampling on every `scrollContentsBy` walks every vertex. | standing | [01](../01-canvas-geometry.md#pf-can-26) |  |
| PF-CAN-27 | Never paint a texture with a pen. A `QPen` whose brush is a texture is right on screen, in PNG and in PDF, but `QSvgGenerator` writes a pen as its colour, and a texture brush's colour is black. Fill the outline instead: `QPainterPathStroker` (width, cap, join) and `drawPath(stroker.createStroke(path))` with `NoPen` and the texture brush. The SVG then carries a pattern fill. | standing | [01](../01-canvas-geometry.md#pf-can-27) |  |
| PF-CAN-28 | Exclude underpaint from a translucent textured path; rim masking must follow the device transform, remain bounded and preserve bends and self-crossings. | standing | [01](../01-canvas-geometry.md#pf-can-28) |  |
| PF-CAN-29 | A parenting clamp must follow the GEOMETRY, not only the link: a plant renders above the plant-parent whose outline contains its stable centre, linked or not. When a visual guarantee can be satisfied by a category accident (a ground surface sitting under everything), check the guarantee on the categories where the accident does not apply. | standing | [01](../01-canvas-geometry.md#pf-can-29) |  |
| PF-CAN-30 | Offset path inner bends intersect before the corner and create self-intersecting loops if segment endpoints are connected naively; trim overlapping segments to the intersection at acute inner bends ($offset \cdot (\vec{u}_1 \times \vec{u}_2) > 0$). In paved path rendering, base fill pen join must match border chord (`BevelJoin`) to eliminate miter spikes. | standing | [01](../01-canvas-geometry.md#pf-can-30) |  |
| PF-CAN-31 | Rounded gravel relief follows the painted stroke rim, including caps; nominal analytical caster footprints cannot prove decorative rim coverage or exclusion. | standing | [01](../01-canvas-geometry.md#pf-can-31) |  |
| PF-CAN-32 | A relationship other surfaces read must be reconciled by EVERY edit path that can invalidate it, through one mutator and one geometric rule. Recompute membership inside the move/resize/rotate/vertex/copy command, so undo restores it in the same step — never at one call site; and scope a bed edit to the plants that bed can affect, or it will overrule a plant's deliberate link to another bed. | standing | [01](../01-canvas-geometry.md#pf-can-32) |  |
| PF-CAN-33 | An item's derived centre is `rect().center()`, never `width/2, height/2`: a circle's rect is built at `centre - radius`, so its local origin is not `(0, 0)` and the half-size value names a different point. | standing | [01](../01-canvas-geometry.md#pf-can-33) |  |
| PF-CAN-34 | A derived visual belongs to the item that owns it: bake it into that item's geometry (or its own serialized state), never add a second free scene item. A separate decoration does not follow the host when it moves or groups, is not deleted with it, and is not part of its undo/save. | standing | [01](../01-canvas-geometry.md#pf-can-34) |  |
| PF-CAN-35 | An open path has no inside: offsetting a polyline creates a parallel LINE on the cursor's side, never a filled polygon. Clipper-1 returns the stroked band outline for an open path; take the outline as an area only after proving the source is closed. | standing | [01](../01-canvas-geometry.md#pf-can-35) |  |
| PF-CAN-36 | A `QGraphicsItemGroup`'s child reports `isSelected() == True` while only the group is selected (Qt propagates selection into group children). An operation that acts on "the selection" must filter to the level it is defined at — group/ungroup count only TOP-LEVEL groups (`parentItem() is None`) — or one gesture dissolves nested levels. | standing | [01](../01-canvas-geometry.md#pf-can-36) |  |
| PF-CAN-37 | Two item classes that can represent the same semantic object must render it through ONE shared paint path. Making a rectangle convertible into a HOUSE also obliges its `paint()` to take the ridge-aware tile fill; otherwise the converted house is a flat, wrongly-lapping roof beside a correctly-drawn one. | standing | [01](../01-canvas-geometry.md#pf-can-37) |  |
| PF-CAN-38 | A derived top-level sibling whose owner can be grouped (a HOUSE's `ROOF_RIDGE`) must re-run the stacking derivation when the owner joins or leaves a group; the normalizer resolves the owner inside the group to the GROUP, and only that refresh puts the sibling above the group's fill. | standing | [01](../01-canvas-geometry.md#pf-can-38) |  |
| PF-CAN-39 | Selecting with Shift AND Ctrl must go through the app's own toggle path (`SelectTool._selectable_under` + `setSelected`), not Qt's default press; and a selectable item under the cursor must be found with `QGraphicsScene.items(point)`, never `itemAt` alone — `ItemIgnoresTransformations` items (journal pins) are invisible to `itemAt` under the Y-flipped view. | standing | [01](../01-canvas-geometry.md#pf-can-39) |  |
| PF-CAN-40 | `QGraphicsScene.itemAt` never returns an `ItemIgnoresTransformations` item (measured on Qt 6.12, with or without the canvas Y flip), so a constant-screen-size item such as a journal pin needs its own hit test. The view must also drive the interaction it owns - select/toggle, drag with one undo step, double-click - because Qt's press path cannot start it. | standing | [01](../01-canvas-geometry.md#pf-can-40) |  |
| PF-CAN-41 | A thumbnail or export pass that masks overlay items must suppress their PAINT, not their visibility. Qt deselects an item when it is hidden, so `setVisible(False)`/`True` around a periodic render clears the user's selection; `ItemHasNoContents` masks paint without changing visibility, selection or the plan revision. | standing | [01](../01-canvas-geometry.md#pf-can-41) |  |
| PF-CAN-42 | A bespoke drag path must end through one finalizer on every exit - release, a release lost outside the viewport, and the next press - and a guard that suppresses a move because a `ResizeItemCommand`/`RotateItemCommand` already exists must be scoped to the gesture that created it (compare the undo depth at drag start), never to the stack top. | standing | [01](../01-canvas-geometry.md#pf-can-42) |  |
| PF-CAN-43 | A rect that depends on anything outside the item (a plant's on the plan date) reads that input through a value changed only AFTER `prepareGeometryChange`. Qt's BSP index takes an item out of the leaves of the rect it has at that call; told after the rect moved, the old leaves keep the pointer, and it dangles once the item is removed and destroyed. | standing | [01](../01-canvas-geometry.md#pf-can-43) |  |
| PF-CAN-44 | A sprite whose natural aspect is opposite its item's is TURNED a quarter, never stretched; the 3D builder must build the same turn from the same rule. | standing | [01](../01-canvas-geometry.md#pf-can-44) |  |
| PF-CAN-45 | Every ridge path asks one predicate (`is_ridge_bearing_type` / `is_ridge_bearing_kind`), never `object_type == HOUSE`; adding a ridge-bearing kind means adding it to `RIDGE_BEARING_KINDS` and nothing else. | standing | [01](../01-canvas-geometry.md#pf-can-45) |  |
| PF-CAN-46 | A `QGraphicsItemGroup` child cannot be selected independently: selecting it selects the group, and its resize/vertex handles do not receive a usable drag. Group drill-down is therefore a VIEW-LEVEL logical focus (`drill_down_item` / `effective_selection`), never a reparent or a temporary ungroup. | standing | [01](../01-canvas-geometry.md#pf-can-46) |  |
| PF-CAN-47 | `QPainterPath.intersects` is true for a boundary touch, not only for an interior crossing. A geometry operation that means "crosses" must prove interior overlap — for a segment, split it at its outline crossings and require an interval midpoint strictly inside — or a snapped corner pick silently cuts the shape it only grazed. | standing | [01](../01-canvas-geometry.md#pf-can-47) | 11.4.22 |
| PF-CAN-48 | `QGraphicsItem.setFlags` deselects any item that reports `isSelected()` without being selectable, and a descendant that already existed when its parent joined a `QGraphicsItemGroup` reports its GROUP's selection: one flag set on such a handle inside a selected group unselects the whole group. Code that toggles a flag on arbitrary scene items (the minimap's overlay suppression) must test exactly that condition and hide those items by opacity. | standing | [01](../01-canvas-geometry.md#pf-can-48) |  |
| PF-CAN-49 | Qt keeps every item's `DeviceCoordinateCache` picture in the process-wide `QPixmapCache`, whose default limit is 10 MB; a canvas raises it (`ui/canvas/item_cache.ensure_item_cache_budget`, 256 MB) or its item caches thrash and every repaint paints the items again. Setting a cache mode proves nothing: count the paints. | standing | [01b](../01b-canvas-rendering.md#pf-can-49) |  |
| PF-CAN-50 | A bitmap drawn through a painter is rasterised for THAT painter: ask `core/raster_resolution` (device scale of the painter, rounded up to a power of two, never below 1) through `paint_plant` / `paint_furniture` / `brush_for_painter`, never hand a renderer the item's size in centimetres as pixels, and never rasterise a sprite whole when it would exceed 1024 px a side. | standing | [01b](../01b-canvas-rendering.md#pf-can-50) |  |
| PF-CAN-51 | Whatever marks an object (selection handles, the rotation handle, a label anchor) reads `handle_geometry.selection_frame_rect(item)`, never `boundingRect()`; and an `ItemIgnoresTransformations` label is centred or stacked in its own pixel frame, never by an offset written into its position. | standing | [01b](../01b-canvas-rendering.md#pf-can-51) |  |
| PF-CAN-52 | Text that the view scales (a `TextItem` note, a callout) is laid out unhinted (`PreferNoHinting`); text with a halo strokes the glyph outline path, because `drawText` with a wide pen outlines nothing, and takes that outline from the layout that draws the glyphs, never from `QPainterPath.addText`. | standing | [01b](../01b-canvas-rendering.md#pf-can-52) |  |
| PF-CAN-53 | The scene is never painted into a `QSvgGenerator` directly: it is painted into the recording engine of `services/svg_export.py` and replayed, because the generator drops a brush's own transform and a pixmap's source rectangle, and writes a clip either not at all or as a staircase. | standing | [01b](../01b-canvas-rendering.md#pf-can-53) |  |
| PF-CAN-54 | A `paint()` clips with `Qt.ClipOperation.IntersectClip`, never with the default `ReplaceClip`: the painter it is handed already carries the clip of a print tile or a report frame, and replacing it paints on the margin. | standing | [01b](../01b-canvas-rendering.md#pf-can-54) |  |
| PF-CAN-55 | A scale bar's length is its label's distance at the scale its picture was painted at: pick a round distance that fits, never clamp the bar, and take the scale from the fitted rectangle, not from the frame's width. | standing | [01b](../01b-canvas-rendering.md#pf-can-55) |  |
