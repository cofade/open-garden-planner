# Internationalization Pitfalls (PF-I18)

| ID | Rule | Status | Where | Legacy |
|---|---|---|---|---|
| PF-I18-01 | Labels for unnamed objects in translated rows and tooltips come from `get_translated_display_name` at display time, never from title-cased enum identifiers, and user-given names are kept. | standing | [05](../05-i18n.md#pf-i18-01) |  |
| PF-I18-02 | `test_german_ts_has_no_unfinished` checks only the messages already in the `.ts` catalogue, so English that bypasses `tr()` needs the source-level scan `TestNoHardcodedEnglish`. | standing | [05](../05-i18n.md#pf-i18-02) |  |
| PF-I18-03 | Each `tr()` placeholder is paired with its interpolation, `{named}` with `.format()` and Qt `%N` with `.replace()`, preferring `{named}`; crossing them silently shows a raw, untranslated placeholder. | standing | [05](../05-i18n.md#pf-i18-03) |  |
| PF-I18-04 | The `TRANSLATIONS` literal in `scripts/fill_translations.py` keeps unique top-level keys, because a repeated context key silently drops the earlier block's strings from the registry. | standing | [05](../05-i18n.md#pf-i18-04) |  |
| PF-I18-05 | A shared Qt-free service that renders a bilingual data field passes the UI language from `active_language()` instead of relying on a `lang` default, and keeps persisted ids on the stable English name. | standing | [05](../05-i18n.md#pf-i18-05) |  |
| PF-I18-06 | Every `property_name` passed to `ChangePropertyCommand` is registered with its German under the `Commands` context in `scripts/fill_translations.py`, or the undo text renders half-English. | standing | [05](../05-i18n.md#pf-i18-06) |  |
| PF-I18-07 | Register new strings in `scripts/fill_translations.py` and never re-extract the `.ts` with `pylupdate6` over the source tree, which rewrites the whole file and marks untouched messages unfinished. | standing | [05](../05-i18n.md#pf-i18-07) |  |
| PF-I18-08 | A translation gate derives its required keys from live source, independently of the catalogues it checks, and requires each key completed in every registered locale and in the compiled lookup. | standing | [05](../05-i18n.md#pf-i18-08) |  |
