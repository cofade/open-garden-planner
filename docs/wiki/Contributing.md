# Contributing

The repository's [CONTRIBUTING.md](https://github.com/cofade/open-garden-planner/blob/master/CONTRIBUTING.md)
owns contribution instructions, setup, quality checks, testing, translations, and review requirements.
Use that guide rather than a second copy of development commands here.

## Choose work

- Read the [Roadmap](Roadmap) and [Architecture](Architecture).
- Browse [open issues](https://github.com/cofade/open-garden-planner/issues) for confirmed work.
- Use [Discussions](https://github.com/cofade/open-garden-planner/discussions) for public questions and ideas.
- Coordinate in the issue before starting substantial work.

AI-assisted contributions are welcome. Contributors remain responsible for the changes and their evidence.
Every user story requires an end-to-end integration test. Bug fixes need an appropriate regression test.
Documentation changes require documentation checks, not an unrelated UI test.

- [Code of Conduct](https://github.com/cofade/open-garden-planner/blob/master/CODE_OF_CONDUCT.md)

Discussions and ordinary issues are public. Private abuse reports go to GitHub Support.
Private vulnerability reports use the separate GitHub security form and go to repository maintainers.
