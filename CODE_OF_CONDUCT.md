# Code of Conduct

## Expected behaviour

- Treat people with respect, regardless of identity, background, disability, or experience.
- Discuss the work without personal attacks.
- Accept constructive criticism and correct mistakes.
- Respect privacy. Do not publish another person's private information without permission.
- Do not harass, threaten, discriminate, or use unwanted sexual language or imagery.
- Do not spam project spaces or deliberately disrupt discussions.

These rules apply to issues, pull requests, discussions, wiki contributions,
and other spaces where people represent Open Garden Planner.

## Moderation

The repository maintainer, **@cofade**, moderates project spaces.
The maintainer may remove content, lock conversations, warn participants, or block participation
when behaviour violates these rules. The response depends on the severity and repeated behaviour.
Moderation decisions should be fair and should explain the reason when appropriate.

## Report abuse

For a private abuse report, use GitHub's **Report content** action on the relevant item or comment.
You can also use GitHub's [abuse-report contact form](https://support.github.com/contact/report-abuse).
Follow [GitHub's reporting instructions](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).

These private reports go to **GitHub Support**, not directly to this repository's maintainer.
GitHub handles them under its own policies. The project provides no private maintainer inbox or public contact email.
GitHub Discussions and ordinary issues in this repository are public.
Do not publish sensitive details in them to request moderation.

For a non-sensitive request, flag the relevant public content to @cofade without repeating abusive or private material.
If the complaint concerns the maintainer, use GitHub Support.
Report software vulnerabilities through the separate process in [SECURITY.md](SECURITY.md).
